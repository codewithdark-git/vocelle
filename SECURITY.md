# Security policy

## Supported versions

Security fixes go into the latest release. Please update to the
[latest version](https://github.com/codewithdark-git/vocelle/releases/latest)
before reporting.

## Reporting a problem

Please report security problems privately, not in a public issue:

1. Open the repository's **Security** tab and click **Report a vulnerability**.
2. Describe the problem, the version and platform, and the steps to reproduce it.

If that button isn't available, open an issue titled "Security contact" with
no details, and we'll reply with a private way to send them.

You'll get a reply within a week. Once a fix is released, the release notes
will credit you unless you'd rather stay anonymous.

## Scope

Vocelle runs entirely on your computer. Things we especially want to hear about:

- Ways another program or web page could make Vocelle type, record or reveal text.
- Model downloads that could be tampered with (they're checked with SHA-256).
- Data written somewhere other than the folders listed in the
  [README](README.md#configuration), or kept after you delete it.
- Problems in the installers or the release process.
